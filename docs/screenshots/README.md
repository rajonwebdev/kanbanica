Guidelines for adding or refreshing one:

- **Use demo data only.** Never capture real user names, real email addresses, or
  customer content — these images are published in a public repository and cannot
  be removed from git history afterwards.
- **Dark mode**, to match the current set — keep new captures consistent with the
  existing ones rather than mixing themes. 1600px wide or larger, PNG.
- Keep each file under ~500 KB so clones stay small.
- Filenames are lowercase, matching exactly what `README.md` embeds — GitHub's
  file hosting is case-sensitive even where your local filesystem isn't.
